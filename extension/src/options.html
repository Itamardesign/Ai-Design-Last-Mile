Accepted formats

All of these describe the same thing, and all of them are read.

Plain / hand-written

{
  "name": "Acme",
  "colors": {
    "brand-500": "#7C3CFF",
    "text-body": "#172033",
    "surface": "#F6F8FF"
  },
  "spacing": { "sm": "8px", "md": "16px" },
  "radius": { "card": "12px" },
  "typography": {
    "h1": { "fontSize": "32px", "fontWeight": 600 }
  }
}

DTCG / Style Dictionary

{
  "color": {
    "brand": {
      "500": { "$value": "#7C3CFF", "$type": "color" }
    }
  },
  "spacing": {
    "md": { "$value": "16px", "$type": "dimension" }
  }
}

Tailwind config (as JSON)

{
  "theme": {
    "extend": {
      "colors": { "brand": { "500": "#7C3CFF" } },
      "borderRadius": { "card": "12px" },
      "fontSize": { "xl": ["24px", { "lineHeight": "1.3" }] }
    }
  }
}

Inspector tokens (exact shape)

{
  "collections": [{
    "id": "product",
    "name": "Product",
    "colors": [{ "label": "Brand", "value": "#7C3CFF", "usage": "accent" }],
    "typography": [{ "label": "H1", "sample": "Heading", "css": "font-size: 32px" }]
  }],
  "spacing": [{ "name": "md", "value": "16px" }],
  "radius": [{ "name": "card", "value": "12px" }]
}

Connecting a real system also unlocks token binding, the page token audit and “apply to all variants” — the three features that need a source of truth rather than a guess.
